# Gute Ideen einreichen

Danke fürs Mitdenken! Der Schwarm soll Erkenntnisse teilen, keine persönlichen Daten.

## Vorschlagsvorlage

**Anwendungsfall:** Welches Problem löst die Idee?  
**Ansatz:** Wie könnte sie funktionieren?  
**Synthetischer Testfall:** Welche erfundenen Daten und erwarteten Ergebnisse belegen die Idee?  
**Grenzen/Risiken:** Welche Fehlfälle sind denkbar?  
**Quellen und Lizenz:** Was darf öffentlich verwendet werden?  
**Datenschutzprüfung:** Bestätigung, dass keine fremden oder privaten Inhalte enthalten sind.  
**Kosten/Voraussetzungen:** Welche Software, Hardware oder externen Dienste werden gebraucht?

Nur geprüfte Ideen können später als kuratierter Artikel auf reith-privat.de erscheinen. Eine GitHub-Diskussion ist **keine automatische Veröffentlichungsfreigabe**.

Für konkrete Codebeiträge: kleine nachvollziehbare Änderungen mit Tests und sicherem Rückweg. Keine Produktions-Configs, Zugangsdaten oder Live-Kopien.
