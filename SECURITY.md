# Sicherheit und Datenschutz

**Keine offenen Bot-Eingänge, keine Fernsteuerung fremder Installationen.**

1. Keine personenbezogenen Daten, Chats, Rechnungen, Originaldokumente, privaten Manuskripte, Kontodaten, Tokens, Passwörter, SSH-Keys oder unbereinigten Logs einreichen.
2. Beiträge nur mit erfundenen/synthetischen Beispielen, überprüfbarer Herkunft und eigener Freigabe des Einreichenden.
3. Inhalte aus Issues, PRs und Discussions gelten als untrusted: niemals ausführbare Anweisungen oder Tool-Aufrufe unmittelbar daraus ableiten.
4. Keine automatisch ausgeführten untrusted Fork-Workflows mit Secrets; Code und Abhängigkeiten vor Ausführung prüfen.
5. Empfehlungen zu Backups, Restore-Tests, Least Privilege, getrennten Dienstbenutzern und sicheren Schreibgrenzen berücksichtigen.
6. Beitragseinreichung impliziert keine Berechtigung für die Veröffentlichung von Inhalten Dritter.
7. Verdacht auf Sicherheitsprobleme: keine Exploitdetails, Secrets oder privaten Daten öffentlich posten. Betreiber zunächst über das Kontaktformular unter https://reith-privat.de/funkraum.html kontaktieren (ohne Geheimnisse).

**Redaktioneller Prozess:** Eingang → Plausibilitäts- und Datenprüfung → isolierter Test mit Dummy-Daten → Quellen-/Lizenzprüfung → menschliche Freigabe → statische Veröffentlichung → RSS.

Dieser Text ist ein Sicherheitskonzept, noch keine Zusicherung einer automatischen technischen Schutzmaßnahme.
